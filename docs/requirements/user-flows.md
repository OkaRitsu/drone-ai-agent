# ユーザーフロー
## 1. オンボーディングフロー
### 初回セットアップ
1. ドローンを登録（接続情報をyamlファイルなどに設定）
## メインフロー
### ドローンの起動からAIアプリセットアップ
目的：ドローンを起動し、AIと接続する。
1. ドローン（TELLO）を起動
2. 使用PCのアクセスポイントにTELLOを追加（インターネットとの両立必須）
3. マインプログラム実行
4. 監視用のダッシュボード起動
5. ドローンの状態・映像ストリーミング開始
6. MCPサーバ起動
7. ユーザが接続先のAIアプリ操作
8. AIアプリからドローンの状態を確認
成功条件：AIエージェントがドローンの状態を確認で切る状態
### 自然言語によるドローン操作
目的:ユーザが意図した通りの飛行を実現する。
1. AIアプリに対して指示入力
2. AIアプリがMCPツールを利用しドローンを操作
3. タスクが完了するまでAIアプリ上でやり取り
成功条件：タスクを完了し、ドローンが着陸した状態
### ドローン飛行レポート
目的: 飛行結果をユーザに知らせる。
1. ドローンが着陸
2. 飛行ログを取得し、AIエージェントがサマリを作成
3. 会話履歴から得られた情報をまとめる
成功条件:飛行ログを活用し、レポートを作成できる状況
