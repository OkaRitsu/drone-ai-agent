# ドローンAIエージェント
## 概要
ドローンを専門知識を持たないユーザが利用できるようにするAIエージェント。
ユーザが自然言語で指示をすることでドローンが動作し、自律的にタスクを完了するプラットフォーム。
ユーザが閲覧するためのダッシュボードの他、AIとドローンを連携するための仕組みを提供する。
## 解決する課題
ドローンを活用しようとしたとき、操縦方法だけでなく多くの経験が求められる。
特に、ドローンを目視外で使用する際には高度に空間を把握する必要があり、十分な経験を持たないユーザにとってはハードルとなる。
そのため、ドローンにおける経験を多く持たないユーザも意図したとおりにドローンを活用できるようにする。
## 主要機能
* ドローン操縦（離着陸、前後左右移動、回転）
* 映像のモニタリング
* ドローンの状態のモニタリング
* ドローン映像の解析
