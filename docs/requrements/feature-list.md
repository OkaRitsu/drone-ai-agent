# 機能一覧
## 優先度判例
1. Must Have（MVP必須）
2. Shuould Have（MVP後優先）
3. Nice to Have（将来対応）
## 1. リアルタイムモニタリング
| 機能名 | 説明 | 優先度 | 備考 |
|--------|------|--------|------|
| ダッシュボード | プログラム実行時にダッシュボード起動 | 1 | [rerun](https://rerun.io/)を使用 |
| 映像ストリーミング | ダッシュボードにドローンの映像をリアルタイムで表示 | 1 |  |
| 状態表示 | ドローンの状態を時系列で可視化 | 1 |  |
| 補助機能の結果可視化 | SLAMや画像認識結果を可視化 | 2 | |
## 2. MCPサーバ
| 機能名 | 説明 | 優先度 | 備考 |
|--------|------|--------|------|
| ドローン状態取得 | バッテリやその他の状態を取得 | 1 | [TELLO SDK](https://dl-cdn.ryzerobotics.com/downloads/Tello/Tello%20SDK%202.0%20User%20Guide.pdf)を参考 |
| ドローン映像取得 | 現在ドローンカメラで捉えている映像を1フレーム取得 | 1 |  |
| ドローン操縦 | 指定した方向・大きさ・速度でドローンを操作 | 1 |  |
| 飛行ログ取得 | 指定した期間のドローンのログを取得 | 2 | |
| 補助機能結果取得 | SALMや画像認識結果を取得 | 2 |  |
## 3. ログ保存
| 機能名 | 説明 | 優先度 | 備考 |
|--------|------|--------|------|
| ドローン状態ログ | バッテリやその他の状態をcsvで保存 | 1 |  |
| ドローン映像ログ | 離陸から着陸までの映像をmp4で保存 | 1 |  |
| ドローン操縦ログ | MCPサーバ経由で実行したコマンドを時系列順で保存 | 1 |  |
## 4. 補助機能
| 機能名 | 説明 | 優先度 | 備考 |
|--------|------|--------|------|
| SALAM | 自己位置推定を実施 | 3 | |
| 物体検出 | オープンボキャブラリの物体検出モデルを用いてドローンが見ている物体を検出 | 3 | Deticなど |
| 深度推定 | 嘆願深度推定モデルを用いてドローンが見ている画像から深度画像を取得 | 3 | DepthAnythingなど |
| 特徴点抽出 | ドローンが見ている画像から特徴点を抽出 | 3 | SIFTやALIKEDなど |
